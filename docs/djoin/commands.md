# Commands

|                    Command                    |  Permission |                                               Description                                              |
| :-------------------------------------------: | :---------: | :----------------------------------------------------------------------------------------------------: |
|          /djoin addgroup \[groupname]         | djoin.djoin |                                       Adds a group to the config                                       |
|          /djoin delgroup \[groupname]         | djoin.djoin |                                     Deletes a group from the config                                    |
|      /djoin setmsg \[group] \["message"]      | djoin.djoin |                   Sets a message about the player's login to the server for the group                  |
| /djoin addcmd \[groupname] \[cmd (without /)] | djoin.djoin | Adds a command that is executed by the console each time a player from the group logs on to the server |
|      /djoin delcmd \[groupname] \[index]      | djoin.djoin |                                   Deletes the command from the config                                  |
|          /djoin listcmd \[groupname]          | djoin.djoin |     Displays a list of all commands that are used for this group and indexes for deleting commands.    |
|                 /djoin reload                 | djoin.djoin |                                     Resets the plugin configuration                                    |
