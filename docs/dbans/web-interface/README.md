# 💻 Web Interface

The web interface works with the server through a database.

Only Russian language supports, English soon...

## Features

* Fully customizable
* Switch between light and dark theme
* Open source
* Modern desing
* Page with statistics on punishments
* Moderator's top & Anti-top players by number of penalties
* Admin panel with the ability to edit the punishment: delete the punishment or change its cause
* Connecting to your server via the RCON port and sending commands
* Protection against inserting malicious code into the search form on the website&#x20;
* And more!
