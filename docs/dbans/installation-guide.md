# Installation guide

***

## Supported server cores & Java Requirements

Our plugin is supported and runs on [PaperMC](https://papermc.io/software/paper/), versions at least 1.21. For the plugin to work correctly, you must install [Java 21](https://www.oracle.com/java/technologies/downloads) or higher.

***

## Dependencies

The plugin can only work using [LuckPerms](https://luckperms.net/), otherwise it simply won't start. PermissionsEx is not supported (is anyone else using this?)

If you want to use the prison correctly, then you need to install [Citizens2](https://ci.citizensnpcs.co/job/Citizens2/) on your server, if you don't want to pay, you can install dev-builds on your server (they are completely free).

The [PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI) is necessary for the plugin's external placeholders to work correctly. If you don't need to use placeholders, you don't have to install.
