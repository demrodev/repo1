# Special permissions

## Undo own punishments permissions

|    Permission    |          Description          |
| :--------------: | :---------------------------: |
| dbans.unmute.own | Allows you to unmute yourself |
|  dbans.unban.own |  Allows you to unban yourself |
| dbans.unwarn.own | Allows you to unwarn yourself |
| dbans.unjail.own | Allows you to unjail yourself |

## Cooldown bypass permissions

| :---------------------: | :------------------------------: |
|  dbans.cooldown.bypass  | Bypass cooldown for all commands |
|    dbans.cooldown.ban   |     Bypass cooldown for /ban     |
|  dbans.cooldown.tempban |   Bypass cooldown for /tempban   |
|   dbans.cooldown.mute   |     Bypass cooldown for /mute    |

|   dbans.cooldown.warn   |     Bypass cooldown for /warn    |
|   dbans.cooldown.jail   |     Bypass cooldown for /jail    |
